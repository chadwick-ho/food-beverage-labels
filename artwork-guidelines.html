Artwork Guidelines for Custom Label Printing

Upload finished artwork or send your logo, text and reference image. We will review the file and guide proof preparation.

Accepted Files

PDF, AI, EPS, SVG, PSD, PNG and JPG files are accepted. Vector files are preferred when available.

If Artwork Is Not Ready

Send packaging photo, logo, product text and reference image. We can review what is needed for digital proof.

Before Approval

Check spelling, barcode, nutrition or product information, artwork position and label size carefully.
